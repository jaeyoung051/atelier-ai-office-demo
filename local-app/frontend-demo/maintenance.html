전체 백업·복원

1. DB + 사진 전체 백업

사례·원고·사진·승인·재작성 이력을 ZIP 하나로 저장합니다. API 키와 프로그램 소스는 포함하지 않습니다.

AI 작업이 끝난 뒤 실행하세요. 현재 MVP는 전체 250MB 이하를 지원합니다. 백업은 암호화되지 않으므로 안전한 개인 폴더에 보관하세요.

2. 백업에서 복원

이 프로그램에서 만든 전체 백업 ZIP을 선택하세요. 현재 DB는 유지하고 새 폴더로 복원합니다. 파일 무결성과 사진을 검증한 후에만 완료합니다.

선택 변경은 서버를 종료하고 다시 실행해야 적용됩니다. API 키는 기존 PC 설정을 사용하며, 다른 PC에서는 별도로 설정해야 합니다.
