# Pixffice MVP 2 시작 안내

## 준비
- Mac에 Node.js 22.20.x 설치가 필요합니다. Node가 포함된 설치 앱은 아닙니다.
- 전달 ZIP을 개인 폴더에 풀고 폴더 전체를 함께 보관하세요.
- 전달본에는 가상 사례와 테스트 이미지, 생성·승인·재작성 기록이 포함됩니다. 실제 고객 자료가 아닙니다.
- API 키는 전달본에 없습니다. API설정.command로 설정 파일을 열어 본인 Gemini 키를 입력하세요.
- `GEMINI_API_KEY=` 뒤에 본인 키를 넣고 저장하세요. 채팅이나 역할지시서에 키를 쓰지 마세요.
- 무료 사용을 원하면 Google AI Studio의 무료 등급 프로젝트를 사용하고 결제 상태와 한도를 직접 확인하세요.

## 실행·종료
1. 시작.command를 실행합니다. 기본 주소 http://127.0.0.1:4313/ 이 열립니다.
2. 업무 보드에서 기존 기록을 확인할 수 있습니다. 키가 없어도 기록 조회·편집·백업은 가능합니다.
3. AI 생성·재작성은 키 설정 후 서버를 재시작해야 합니다.
4. 종료.command를 실행하면 서버가 종료됩니다. 브라우저 탭만 닫아서는 서버가 종료되지 않습니다.
5. Mac이 실행을 막거나 Node를 찾지 못하면 터미널에서 이 폴더로 이동 후 `npm run app:start` / `npm run app:stop`을 실행해 오류를 확인하세요. 최초 설치·실행 확인은 친구 Mac에서 별도로 필요합니다.

## 백업·복원
- 앱 메뉴 '백업·복원' 또는 http://127.0.0.1:4313/maintenance 를 엽니다.
- AI 작업이 완료된 상태에서 전체 백업 ZIP을 내려받습니다. DB와 실제 사진이 함께 저장됩니다.
- 전체백업.command를 실행하면 backups 폴더에도 같은 형식의 ZIP을 저장할 수 있습니다.
- 백업은 암호화되지 않으므로 개인 폴더 또는 암호화된 저장장치에 보관하세요. 현재 지원 상한은 250MB입니다.
- 복원 화면에서 이 앱의 전체 백업 ZIP을 선택하고 '새 폴더에 복원'을 누릅니다.
- 기존 데이터를 덮어쓰지 않습니다. restores/recovered-* 폴더를 만들고 무결성을 검사합니다.
- '다음 실행부터 복원본 사용'을 선택한 경우 종료.command → 시작.command 순서로 재실행하세요.
- 다음 실행 데이터 선택은 local-data.json에 기록됩니다. 환경변수 PIXFFICE_DB_PATH를 따로 지정한 경우에는 해당 값이 우선하며 화면에서 활성화가 차단됩니다.
- 복원본 사용을 취소하려면 서버를 종료하고 local-data.json을 다른 이름으로 보관한 뒤 다시 실행합니다. 기본 data 폴더가 다시 열립니다. 데이터 폴더를 삭제할 필요는 없습니다.
- 단독 DB 복사만으로는 사진이 복구되지 않습니다. 반드시 전체 백업을 사용하세요.

## 게시 준비
- 마케팅 사례 → 원고 생성 → 업무 보드 채널 탭 → 사진·본문 수정 저장 → 개별 승인.
- 반려는 사유 입력 후 저장하고 '반려 사유로 Gemini 재작성'을 누릅니다. 새 원고는 다시 승인해야 합니다.
- 승인본은 문구 복사/TXT/원고+사진 ZIP으로 가져갑니다. ZIP의 post.html은 참고용입니다. 네이버 블로그 편집기에 본문과 사진을 직접 등록하세요.
- 실제 SNS 계정 연결·자동/예약 게시는 구현되지 않았습니다. 가상 사례·테스트 이미지는 실제 홍보물로 게시하지 마세요.

## 다른 컴퓨터로 이전
- 프로그램 폴더와 전체 백업을 함께 옮기고 Node.js를 설치합니다.
- 새 PC의 API 키는 별도로 설정합니다. 기존 PC의 .env 파일은 공유하지 마세요.
- Windows는 Node/npm 구조를 고려했지만 실제 기기 테스트는 하지 않았습니다. .command 파일은 Mac 전용입니다. Windows에서는 npm 명령을 사용하세요.

## 검증 범위
- 현재 Mac 환경에서 자동 테스트 14개 그룹 통과.
- 다른 폴더로 복원 후 서버 실행, DB·사진·원고·승인 이력 조회 일치 확인.
- 복원본을 다음 실행 대상으로 선택하고 종료·재실행 확인.
- 친구 Mac M1 8GB와 Windows 실기기 테스트, 서명된 설치 앱 제공은 아직 남아 있습니다.
