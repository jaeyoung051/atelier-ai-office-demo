# MVP4 제안서 제작 자동화 - 1차 구현

2026-11-16. MVP3 현장 업무 기능과 별도로 진행합니다. 부분 입고 개발은 적용하지 않았습니다.

## 사용 순서
1. 기존 실행 방법으로 로컬 앱을 켭니다. `npm run app:start`, http://127.0.0.1:4313/#marketing
2. 마케팅·포트폴리오 아래 제안서 작업함의 **MVP4 제안서 제작 자동화**에서 대상 현장·제목·고객 요청·조건을 입력합니다.
3. 참고 사례 최대 3개와 같은 현장의 승인 견적(선택)을 고릅니다. 자료·역할·업무기준은 설정된 AI 제공사에 전송됩니다. 사진 파일은 AI에 전송하지 않습니다.
4. 제안서 초안 생성 → 원고 검토. 필요하면 원고를 직접 수정하고 **원고 수정 저장·재검토**를 누릅니다. 이전 원고 버전과 승인 기록을 보존합니다.
5. **업무 보드에서 검토** → 최종 승인 또는 반려. 승인 이후 자동 제작 영역에서 다시 조회하면 **제안서 출력·PDF 저장** 링크가 표시됩니다.
6. 출력 문서에는 제목·현장·승인 원고와 참고 사례 사진(사례당 최대 5장)이 들어갑니다. 실제 사진이 없으면 첨부 없음으로 표시합니다. 인쇄 창에서 PDF로 저장할 수 있습니다. 외부 발송은 직접 진행합니다.

## 이번에 구현한 범위
- 현장·요청·조건·참고 사례·승인 견적을 입력 자료로 조합한 Gemini 초안 생성
- 제안 개요, 해결 방향, 공간별 계획, 참고 사례, 예산·진행 단계, 확인 필요 항목을 요청하는 생성 지시
- 생성 시점 자료 전체 스냅샷. AI에는 일부 요약을 전송하므로 세부 자료 누락 여부를 검토해야 합니다.
- 가상 사례와 참고 실적을 구분하고, 미확인 금액·일정을 지어내지 않도록 지시
- 수정 버전 저장, 기존 업무 보드 승인·반려 연결, 승인된 버전만 출력
- 같은 생성 요청 ID의 재전송 시 중복 AI 실행 방지. 실패한 생성은 새 요청으로 다시 생성합니다.
- 브라우저 인쇄용 HTML 및 OS PDF 저장. 서버 직접 PDF 다운로드나 PPTX 생성은 미구현
- 사진 분석, 고객 자동 발송, AI 운영실장 자동 검수, 자동 재작성은 미구현
- 참고 사례 사진 선택·배치 편집, 회사 정보·표지 템플릿, 페이지별 편집, 전문 PPTX/PDF 조판은 다음 단계

AI 출력은 사실 검증을 보장하지 않습니다. 자동 출력 전에 사용자 검토·승인이 필요합니다. 승인 견적을 첨부해도 AI가 금액을 올바르게 인용했는지 확인하세요. 생성 후 원본 자료 변경은 기존 제안서에 자동 반영되지 않습니다. 새 자료로 다시 생성·승인해야 합니다.

## 파일·DB
- `backend/proposals.ts`, `frontend-demo/proposal-automation.js`
- `backend/migrations/011_proposal_automation.sql`
- proposal_briefs: 생성 입력·현장·시공 사례·견적 스냅샷, tasks와 1:1
- proposal_versions: task별 원고 버전 UNIQUE. 승인 기록은 기존 approvals 사용
- 기존 DB·사진 백업에 자동 포함. 로컬 API키는 백업·소스 전달에서 제외
- GET/POST `/api/proposal-automation`, POST `/:id/save`, GET `/:id/print`

## 확인한 결과
테스트 25개 통과: 기존 MVP3, 생성 요청 재실행, 자료 스냅샷, 원고 수정·버전 충돌, 수정 후 재승인, 미승인 출력 차단, 출력 내용 HTML 이스케이프.
실제 설정된 Gemini로 가상 현장+31평 가상 사례의 제안서 생성 → SQLite 저장 → 업무 보드 승인 → 사진 포함 출력 화면까지 확인했습니다. 실제 PDF 파일 생성·다운로드와 PPTX는 완료로 보고하지 않습니다.
