# Claude PPT용 자료 분석·프롬프트 제안

마케팅·포트폴리오 상단의 'Claude PPT용 프롬프트 만들기'에서 사용합니다.

1. 설계서(PDF/이미지)와 렌더링(PNG/JPG/WebP)을 선택합니다. 최대 4개, 파일당 8MB·전체 12MB 이하입니다. 큰 도면은 관련 페이지를 추리거나 확대 캡처하세요. CAD/HWP/PPTX는 현재 지원하지 않습니다. 암호화된 PDF는 풀어서 준비하세요.
2. PPT 목적과 확정 품목·규격·브랜드·자재·금지 변경사항을 입력합니다. 실제 확인한 정보만 입력하세요.
3. 전송 동의 후 자료 분석을 누르면 파일 내용과 입력 내용이 Google Gemini로 전송됩니다. 기존의 '사진을 AI에 보내지 않는 제안서 원고 생성' 기능과 별도 기능입니다.
4. 파일 번호·위치별 시각 근거, 불확실한 품목, 도면·렌더링·사용자 요구사항 간 충돌을 검토합니다. 생성된 프롬프트를 직접 수정할 수 있습니다. 사진만으로 실제 재질·정확한 수량·규격을 확정하지 않습니다.
5. 원본 대조 확인란 → 검토 내용 저장 → 프롬프트 복사 또는 프롬프트+동일 자료 ZIP 다운로드.
6. ZIP의 F1/F2 자료를 Claude에 직접 첨부하고 txt 프롬프트를 붙여넣습니다. PPTX 제작은 Claude에서 진행합니다. 이 앱은 Claude에 자동 전송하거나 PPTX를 생성하지 않습니다.

프롬프트는 반복 분석·긴 재요약을 줄이기 위한 요약입니다. Claude가 같은 자료를 받으면 이미지 입력 토큰과 PPT 제작 비용은 발생합니다. 총 토큰이 최소이거나 비용이 줄어든다고 보장하지 않으며 실제 절감률은 측정하지 않았습니다. 표시하는 글자 수는 토큰 수가 아닙니다.

현재 사전 분석 제공사는 기존 키를 사용하는 Gemini입니다. GPT 시각 분석 선택은 아직 추가하지 않았습니다. 모델이 이미지/PDF 입력과 JSON 출력을 지원해야 합니다. 제공사 오류·입력 제한은 실패 상태로 남기고 자동 재시도하지 않습니다. 실패 후 새 분석을 원하면 입력을 수정해 새 요청을 만드세요. 같은 요청 재전송은 중복 실행을 막습니다.

자료는 다른 포트폴리오 사진에 섞이지 않고 별도 로컬 자료로 저장합니다. SQLite에 분석·프롬프트·검토 여부·자료 연결을 보관합니다. 이미지/PDF 원본은 로컬 media 폴더에 보관하고 전체 백업/복원에 포함합니다. PDF는 브라우저 내 자동 미리보기 대신 파일로 내려받습니다. 공개 호스팅에 파일이나 DB를 업로드하지 않습니다.

구현 파일: backend/ppt-prompts.ts, backend/gemini.ts, frontend-demo/ppt-prompts.js, migrations/012_ppt_prompt_briefs.sql.
검증: 자동 테스트 28개 통과. 이미지/PDF 바이너리 전송, 구조 검증, 중복 요청 방지, 미검토 내보내기 차단, 파일 일치·백업/복원 확인. 실제 Gemini에 자체 제작 가상 주방 이미지를 보내 6개 항목과 1,210자 지시문을 생성·검토 저장·재조회했습니다. 실제 고객 설계서·렌더링의 인식 정확도와 Claude PPT 제작 결과는 사용자 자료로 별도 검토해야 합니다.

공식 근거: https://ai.google.dev/gemini-api/docs/image-understanding 및 https://ai.google.dev/gemini-api/docs/document-processing
