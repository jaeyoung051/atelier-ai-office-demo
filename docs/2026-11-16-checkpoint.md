# 2026-11-16 개발 체크포인트 - 대면 피드백 전

친구와 만나 현재 기능을 확인하고 수정 범위를 정하기 위한 소스 체크포인트입니다.
공개 시안은 데모로 유지하며 실제 저장·AI 연동은 local-app을 PC에서 실행합니다.

## 오늘 반영한 기능
- 고객·현장: 영업중 / 계약완료 / 공사진행·완료 그룹, 진행 상태 DB 저장
- 제안서 작업함: 현장·상태별 일반 제안서 업무 조회
- MVP3: 자재·단가, 현장별 견적 계산과 승인, 순차 공정표(휴무·양생), 발주·입고 완료 기록
- 승인 견적 → 자재별 발주 요청, 중복 생성 방지, 원본 단가 스냅샷
- 공정표 → 자재 필요일·발주 권장일 연결, 일정 변경 재검토, 변경 이력
- 발주·입고 현황판: 임박·경과·지연·재검토 분류, 현장 필터, 업무 바로가기
- MVP4 1차: 현장 요청·참고 사례·승인 견적으로 Gemini 제안서 초안 생성
- 제안서 원고 수정·버전 관리·업무 보드 승인·반려·사진 포함 출력
- 인쇄 창을 통한 견적·제안서 PDF 저장

## 완료 범위와 남은 작업
MVP3는 합의한 로컬 기본 흐름을 구현했습니다. MVP4는 첫 생성·검토·출력 흐름을 구현한 상태입니다.

남은 작업: 회사명·로고·연락처·표지, 사진 직접 선택·순서·설명 편집, 문서 페이지 디자인,
PDF 직접 다운로드·PPTX 제작, 친구 PC 및 대면 사용성 검증, 최신 전달 패키지.
공급처 자동 주문, SNS 자동 게시, 사진 AI 분석, 부분 입고·재고 관리는 구현되지 않았습니다.

## 확인 결과
기존 기능 포함 자동 테스트 25개 통과. 가상 자료로 실제 Gemini 제안서 생성 → DB 저장 →
업무 보드 승인 → 참고 사진 포함 출력 화면을 확인했습니다. 고객 실데이터를 사용하지 않았습니다.

## 실행
Node.js 22.20.x 설치 후 local-app에서 `npm run app:start`.
브라우저 http://127.0.0.1:4313 에 접속합니다. 종료는 `npm run app:stop`.
API 설정은 `.env.example`을 참고해 해당 PC에서 진행합니다. 키는 공유하지 않습니다.

소스에는 API키·실행 DB·사진·백업 ZIP을 포함하지 않았습니다. 처음 실행하면 빈 로컬 DB와
더미 직원/업무기준/가상 단가가 생성됩니다. 기존 PC의 가상 업무 결과까지 GitHub로 이전되지는 않습니다.
세부 안내는 local-app/MVP3_사용안내.md 및 MVP4_제안서_자동화_안내.md를 확인하세요.
